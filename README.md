# CRUD PHP - Git Flow

Sistema de gestión de usuarios desarrollado en PHP aplicando la metodología Git Flow.

## Tecnologías
- PHP
- MySQL
- Bootstrap 5
- Git Flow

## Estructura del proyecto
- `index.php` - Lista de usuarios
- `create.php` - Crear usuario
- `edit.php` - Editar usuario
- `delete.php` - Eliminar usuario
- `login.php` - Formulario de login
- `dashboard.php` - Dashboard con estadísticas
- `search.php` - Búsqueda de usuarios
- `profile.php` - Perfil de usuario
- `validate.php` - Validaciones de entrada
- `helpers.php` - Funciones auxiliares
- `config.php` - Configuración de base de datos
- `users.php` - Funciones CRUD
- `database.sql` - Script de base de datos

## Ramas utilizadas
- `main` - Producción
- `develop` - Desarrollo
- `qa` - Pruebas
- `feature/login-form` - Formulario de login
- `feature/validate-user-input` - Validación de inputs
- `feature/user-dashboard` - Dashboard de usuarios
- `feature/search-users` - Búsqueda de usuarios
- `feature/user-profile` - Perfil de usuario
- `hotfix/fix-date-format` - Corrección de formato de fechas
